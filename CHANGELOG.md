# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0]

### Added

- Arithmetic: `add`, `subtract`, `multiply`, `divide`, `integer_divide`,
  `power`, `modulus`, `absolute`, `root`, `square_root`, `logarithm`,
  `factorial`
- Statistics: `total`, `mean`, `average`, `median`, `mode`, `minimum`,
  `maximum`, `value_range`, `variance`, `standard_deviation`,
  `geometric_mean`, `harmonic_mean`
- Errors: `CalcError`, `DivisionByZeroError`, `EmptySequenceError`
- `calckit-kabanda` command line interface, also runnable as
  `python -m calc_toolkit`
